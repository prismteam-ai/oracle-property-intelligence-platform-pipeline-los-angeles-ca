| Roofing work, coating only                        | A permit whose work description holds a roofing word (`roof_r` or `roof_only`, whole-word matching). "Coating only": roofing work only through COATING TO AN EXISTING ROOF; kept in the permit lists, never sets a roof year.                                                                                                                                                                                                                                                                                                                                                                                                                                | `src/roof-flags.ts`; findings section 14e                                                                                                                                                |
| Status class                                      | `open-issued` (the only class counted as open for long-open), `open-application` (details only), `closed` and `unclear` (Quality Review Completed, CofO in Progress); an unknown status is `unmapped` and counted.                                                                                                                                                                                                                                                                                                                                                                                                                                           | `src/permit-status.ts`; findings section 14f                                                                                                                                             |
| Effective roof year                               | The later of the year built and the year of the status date of the latest finaled roofing permit on the parcel. `roof_age_basis` says which: a year-built PROXY or a PERMIT.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `src/permit-sql.ts`; findings section 14g                                                                                                                                                |
| Long-open                                         | An `open-issued` roofing-work permit open at least the minimum duration (default 1,826 days, five years), counted to the reference date; an optional maximum.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | `apps/api/src/contract.ts` (`DEFAULT_MIN_OPEN_DAYS`); `apps/api/src/routers/permits.ts` (`longOpen`); findings section 14f                                                               |
| Reference date                                    | The date every derived duration counts to (open days, the 10-year ownership proxies, the roof-year cutoff): the permit cache's `generated_at` date (2026-11-17 for the served run, 2026-11-12 for the permits run and its rebuild), never the build date.                                                                                                                                                                                                                                                                                                                                                                                                    | findings section 14k                                                                                                                                                                     |
| Contractor window                                 | Contractor rows exist only for permits issued 2013-01-02 to 2023-05-19 (the `permit_issue_date` range of LADBS's contractor view); a permit issued outside it has no contractor row. `explorer.sources` serves the window as the contractor source's `coverage`.                                                                                                                                                                                                                                                                                                                                                                                             | `apps/api/src/contract.ts` (`coverage`); findings section 14h                                                                                                                            |
| Contractor identity                               | One identity per license number (rule `contractor-identity-1`): the key is the row's license number, trimmed; the canonical name is the license's latest non-null business name (ties: the name on most rows, then byte order). 8,240 license numbers over 101,817 of the 113,642 contractor rows; the 41 licenses with no name on any row have no canonical name (null, never guessed); rows without a license number have no identity. The class is as printed on the permit. Not verified against CSLB.                                                                                                                                                   | `src/contractor-identity.ts`; findings section 14l                                                                                                                                       |
| Land base year                                    | The roll's `Roll_LandBaseYear`: the land's base year under Prop 13, a fiscal-year label ending 30 June. Valid from 1975 to the roll year; 0 (10,964 parcels), the 4 values before 1975 and the one value after the roll year (2027) are null and counted.                                                                                                                                                                                                                                                                                                                                                                                                    | findings section 15                                                                                                                                                                      |
| Ownership basis, ownership filter                 | Three proxies for "owner unchanged for 10 years or more": `recording` (no document recorded in the 10 years before the reference date), `base_year` (land base year at most the latest fiscal-year label whose 30 June is on or before the reference date minus 10 years: 2016) and `both`. Each states its weakness; none is a sale date.                                                                                                                                                                                                                                                                                                                   | `apps/api/src/contract.ts` (`OWNERSHIP_BASIS`, `OWNERSHIP_PROXY_NOTE`); findings section 15                                                                                              |
| Long-open toggle, `parcels.match` window          | `parcels.match` takes `long_open_permit` with the long-open window (`min_open_days`, `max_open_days`) and says which of the given parcel IDs have a long-open roofing permit; at most 72 IDs per call. The CRM's "Has a long-open roofing permit" lead toggle uses it.                                                                                                                                                                                                                                                                                                                                                                                       | `apps/api/src/routers/parcels.ts` (`match`); `apps/api/src/contract.ts` (`MAX_MATCH_IDS`)                                                                                                |
| `places.resolve`                                  | A place name (a jurisdiction or a postal city of the run's parcels) to a center: resolved, ambiguous or unknown, never a guess.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | `apps/api/src/routers/places.ts`; `packages/views/src/place-index.ts`                                                                                                                    |

| Warm-up, held question, re-warm                   | When a panel opens it sends `GET /agent/warm` and two data API requests at once (the warm-up); each takes about 0.8 s, so they are in flight together and two data API environments are warmed. When the last data API response is more than 4 minutes old, the warm-up runs again before the question (re-warm).                                                                                                                                                                                                                              | `apps/explorer/src/warmup.ts` (`HOLD_MAX_MS`, `REWARM_AFTER_MS`, `DATA_WARM_REQUESTS`)                                                                                                   |

| Eval round                                        | One run of the agent eval at a commit: every prompt of the prompts file, a set number of runs each, each answer checked. A round runs 25 prompts three times each (75 answers). A check fails an answer only on what the tool calls, tool results or structured fields verify; a check of how the prose words or places something gives a listed warning. A wrong statement in the prose that none of the fifteen checks covers is not caught. The latest round (17 Nov 2026, run locally on agent commit ebdcf61, the code the hosted agent runs): 75 of 75, with nine listed warnings.                                                                     | `apps/agent-mcp/README.md` ("Eval")                                                                                                                                                      |

| Publish guard                                     | The check that refuses every file but the publish folder's `coverage.json`, the artifact manifest and the two named objects (by name, size and SHA-256): no run manifest, schema, CSV or other Parquet file.                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `src/publish-guard.ts`                                                                                                                                                                   |
| Publication record, `directory.json`              | `runs/<run_id>/publication/directory.json`: the folder's build record (its CID, its file, its CAR's size and SHA-256, the artifact manifest's CID and CAR, the publish-guard result and the scan hits).
