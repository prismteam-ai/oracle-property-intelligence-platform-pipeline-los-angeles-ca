# Glossary (pipeline repository)

Labels used in this repository's commit messages, code comments and docs, with where each is defined. The
CRM repository has its own glossary for the labels used there (hosted test numbers, increment 3).

| Label                                      | Meaning                                                                                                                                                                                                                                        | Defined in                                                                                                                       |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Increment 1                                | The first delivery: a local pilot slice of the LA County Assessor roll 2026 (City of Los Angeles, ZIP 91405, 91406 and 91411; 22,313 parcels). Run `2026-11-11T16-17-38-928Z`.                                                                 | `docs/los-angeles-county-findings.md` "Scope of increment 1"; `config/la-pilot-run.json`                                         |
| Increment 2                                | The hosted data API (`apps/api`) with the shared view contract (`packages/views`), the typed API client (`packages/api-client`) and the Explorer app (`apps/explorer`).                                                                        | Commit messages of 79869c6 and 4023238 ("the increment-2 data API and explorer")                                                 |
| Increment 3                                | The CRM's persisted leads (CRM repository). In this repository, the authorizer passes the client name in its context and publishes its ARN in SSM for the leads API.                                                                           | CRM `apps/crm/cdk/lib/crm-leads-stack.ts` (file header); `apps/api/src/authorizer.ts` (`handler`, which passes `context.client`) |
| Increment 4                                | The county run: all of Los Angeles County, roll 2026, parcels only (2,428,433 parcels). Run `2026-11-12T01-44-04-047Z`, served by the data API.                                                                                                | `docs/los-angeles-county-findings.md` "Scope of increment 4", §11b-§11c; `config/la-county-run.json`                             |
| Slice, pilot slice                         | The increment-1 subset of the roll: one jurisdiction and three ZIP codes.                                                                                                                                                                      | `docs/los-angeles-county-findings.md` "Scope of increment 1"                                                                     |
| Scope guard                                | `src/scope-guard.ts`: before any download or build, it checks that the run config sits inside an approved permit-gate exception (jurisdiction, ZIP set, roll year, no permits).                                                                | `docs/los-angeles-county-findings.md` §10                                                                                        |
| Permit-gate exception                      | An entry under `approved_exceptions` in `docs/los-angeles-sources.yaml` that lets the readiness check pass the permit gate without a permit source, for a stated scope. There are two: the pilot (2026-11-11) and the county run (2026-11-12). | `docs/los-angeles-county-findings.md` §6a                                                                                        |
| Readiness check, preflight                 | The kit's `validate-county-readiness.py`, run by the build (`src/readiness.ts`). Its outputs are kept under `docs/evidence/`.                                                                                                                  | `docs/los-angeles-county-findings.md` §6                                                                                         |
| Run ID                                     | Names one build. It names `runs/<run_id>/`, `data/out/<run_id>/` and the bucket prefix `runs/<run_id>/`. For the pilot it is the raw download directory's name; for the county run, the roll cache summary's `generated_at`.                   | `src/build-outputs.ts` (`runId`)                                                                                                 |
| Run manifest, run history                  | `runs/<run_id>/run_manifest.json` (files, sha256, counts, sources, readiness, limitations) and `runs/run_history.jsonl` (one line per run, with the delta to the previous run).                                                                | `docs/los-angeles-county-findings.md` §13                                                                                        |
| Roll cache                                 | The whole roll downloaded once by `scripts/fetch-roll.mjs` (gzipped pages, `manifest.jsonl`, `summary.json`), outside the repository. The county build reads only from it.                                                                     | `docs/los-angeles-county-findings.md` §11b, §13                                                                                  |
| Tool records                               | `runs/` and `docs/evidence/`: files written by the tools and committed as written, never edited by hand (also kept out of Prettier).                                                                                                           | `.prettierignore`; commit message of 79869c6                                                                                     |
| Points cap, truncated                      | `parcels.points` returns at most 25,000 points, nearest first (`MAX_POINTS`). When more match, the response is marked `truncated`; the count stays complete.                                                                                   | `apps/api/src/contract.ts`; `docs/los-angeles-county-findings.md` §11b                                                           |
| Explorer test numbers ("test 6", "test 7") | The numbered tests of the Explorer's hosted Playwright suite, by the number at the start of each title.                                                                                                                                        | `apps/explorer/e2e/explorer.spec.ts`                                                                                             |
| D8                                         | Used in the message of commit 4023238: the roof-age rule lives in one place, the shared SQL view contract, used by the CLI and the API.                                                                                                        | Commit 4023238                                                                                                                   |
